# GreenOps — PERT-диаграмма

> Формула PERT: **te = (мин + 4 × вероятное + макс) / 6**  
> Дисперсия: **σ² = ((макс − мин) / 6)²**  
> Нумерация дней соответствует рабочим дням, начиная с 1 апреля 2026 г.

## Критический путь

```
T-01/T-02 → T-04 → T-07 → T-11 → T-12 → T-13 → T-15 → T-16 → T-17 → T-32
```

### Номинальная длительность (целые оценки)

```
T-01  2 дня
T-04  2 дня  (T-02 тоже завершается на день 2 — оба питают T-04)
T-07  2 дня
T-11  1 день
T-12  2 дня
T-13  3 дня
T-15  3 дня
T-16  1 день
T-17  1 день
T-32  2 дня
──────────────
Итого: 19 рабочих дней  (1 апр – 25 апр, нулевой буфер)
```

### PERT-ожидаемая длительность критического пути

```
te(T-01) = 2.00
te(T-04) = 2.00
te(T-07) = 2.17
te(T-11) = 1.08
te(T-12) = 2.17
te(T-13) = 3.17
te(T-15) = 3.17
te(T-16) = 1.08
te(T-17) = 1.08
te(T-32) = 2.33
──────────────────────
Ожидаемая длительность до T-32 = 20.25 дня
Номинальный план до T-32       = 19.00 дней
Дельта PERT–номинал            = +1.25 дня
```

### Дисперсия проекта и вероятность соблюдения срока

```
σ²(критический путь) = 0.11 + 0.11 + 0.25 + 0.063 + 0.25 + 0.25 + 0.25 + 0.063 + 0.063 + 0.11
                     = 1.52

σ = √1.52 ≈ 1.23 дня

Z = (номинал − ожидание) / σ
  = (19 − 20.25) / 1.23
  = −1.02

P(завершить T-32 в рамках 19-дневного номинального плана) ≈ 15%
```

> **Критический путь до T-32 имеет лишь ~15% вероятности завершения в рамках точного 19-дневного номинального плана.**  
> Для достижения 50% вероятности требуется ~20.25 дней (+1.25 дня буфера сверх номинала).  
> Для достижения 85% вероятности — ~21.5 дней (+2.5 дня буфера).
